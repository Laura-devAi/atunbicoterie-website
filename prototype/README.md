# Atunbi Coterie prototype

Buildless interactive boutique prototype. Serve `dist/` using a static web server. No dependencies or build step required.

Includes collection filters, product details, sample sizing/bag/removal, scripted stylist recommendations and optional browser speech synthesis. Browser speech availability and voice vary by device. No microphone input, live AI or animated avatar provider is connected. No checkout, payments, order processing or newsletter storage is connected. No customer data is stored.

Products, prices, sizes and names are illustrative. Stock photos are editorial references, not Atunbi merchandise or an approved character. Photography: Unsplash images `photo-1531123897727-8f129e1688ce`, `photo-1539008835657-9e8e9680c956`, `photo-1539109136881-3be0616acf4b`, `photo-1534528741775-53994a69daeb`. Replace with approved brand assets before commercial launch. Typography uses optional Google Fonts with local serif/sans-serif fallbacks.

The speaking portrait preview does not complete the production person-like animated avatar milestone. See the planning repository at https://github.com/Laura-devAi/atunbicoterie-website and Project board https://github.com/users/Laura-devAi/projects/1.

GitHub copy uses externally hosted Unsplash image references; the hosted private preview bundles image files locally. Serve this directory as the static root.
